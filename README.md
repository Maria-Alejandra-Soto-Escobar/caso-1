# caso-1
Análisis descriptivo del rendimiento de jugadores de fútbol usando R y un dataset de FIFA World Cup 2026.

Este proyecto presenta un análisis estadístico descriptivo de jugadores de fútbol utilizando R y el conjunto de datos FIFA World Cup 2026 Player Performance Dataset.

El análisis incluye:

- Exploración y limpieza de los datos.
- Caracterización de los jugadores según posición y edad.
- Análisis de goles y asistencias según la posición.
- Relación entre minutos jugados y calificación.
- Relación entre valor de mercado y rendimiento.
- Elaboración de gráficos y medidas estadísticas para interpretar los resultados.

## Herramientas

- R
- RStudio
- ggplot2
- dplyr
- readr
- tidyr
